Wincy portable
==============

English
-------

1. Extract the whole zip into a folder you can write to (for example
   D:\Tools\Wincy or a USB drive). Do not run wincy.exe from inside the zip.
2. Run wincy.exe. It starts in the system tray; press Alt+V.

The empty file named "portable" next to wincy.exe turns on portable mode:
your history, images, settings and logs are kept in the "data" folder next to
wincy.exe instead of your user profile. Keep "portable" and "data" together
with wincy.exe.

In portable mode Wincy does not start with Windows and does not update itself.
When a new version is out it tells you and opens the download page; to update,
replace wincy.exe and keep the "data" folder. To remove Wincy, quit it from the
tray and delete the folder.

Requires Windows 10 or 11 (x64). https://github.com/devnielo/wincy

Español
-------

1. Extrae el zip completo en una carpeta en la que puedas escribir (por
   ejemplo D:\Herramientas\Wincy o una memoria USB). No ejecutes wincy.exe
   desde dentro del zip.
2. Ejecuta wincy.exe. Se inicia en la bandeja del sistema; pulsa Alt+V.

El archivo vacío llamado "portable" junto a wincy.exe activa el modo portable:
el historial, las imágenes, los ajustes y los registros se guardan en la carpeta
"data" junto a wincy.exe en lugar de en tu perfil de usuario. Mantén "portable"
y "data" junto a wincy.exe.

En modo portable Wincy no se inicia con Windows ni se actualiza solo. Cuando
hay una versión nueva te avisa y abre la página de descarga; para actualizar,
sustituye wincy.exe y conserva la carpeta "data". Para quitar Wincy, ciérralo
desde la bandeja y borra la carpeta.

Requiere Windows 10 u 11 (x64). https://github.com/devnielo/wincy
